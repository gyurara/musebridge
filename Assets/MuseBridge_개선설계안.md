# Bridge Melody — 개선 설계안

> 기존 시스템의 뼈대(판정선 + 다리 배치 + 플레이)는 유지하되,
> 조작 체계 / 다리 높이 / 악기 역할 / 메뉴 시스템을 전면 개편

---

## 1. 조작 체계 개편

### 1-1. 현재 → 변경

| 기능 | 기존 | 변경 |
|------|------|------|
| 악기 선택 | 키보드 1~0, Q~F | **마우스 클릭** (좌측 사이드바) |
| 다리 높이 | 고정 (y=0) | **키보드 1~0** (10단계 높이) |
| 다리 배치 | Space | Space (유지) |
| 이동 (Play) | A/D | A/D (유지) |
| 점프 (Play) | Space | Space (유지) |
| 일시정지 | 없음 | **ESC** |
| 재시작 | 없음 (낙사 필요) | **R키** 또는 일시정지 메뉴 |

### 1-2. Build Phase 조작 흐름

```
① 사이드바에서 악기 클릭 → 선택 (테두리 하이라이트)
② 숫자 키 1~0으로 높이 선택 → 화면에 높이 가이드라인 표시
③ 판정선이 원하는 X 위치에 오면 Space → 다리 배치
```

### 1-3. 높이 시스템 상세

10단계 높이를 숫자 키에 매핑한다.

| 키 | 레벨 | Y 좌표 | 용도 |
|----|------|--------|------|
| 1 | 최저 | -1.5 | 구덩이 바닥 근처 |
| 2 | | -1.0 | |
| 3 | | -0.5 | |
| 4 | | 0.0 | 기본 지면 높이 |
| 5 | | 0.5 | |
| 6 | | 1.0 | 약간 높은 위치 |
| 7 | | 1.5 | |
| 8 | | 2.0 | 높은 플랫폼 |
| 9 | | 2.5 | |
| 0 | 최고 | 3.0 | 최상단 |

화면에는 현재 선택된 높이에 반투명 수평선(높이 가이드)이 표시된다.
판정선과 높이 가이드가 교차하는 지점에 반투명 고스트 다리가 미리보기로 보인다.

스테이지 설계 시 장애물과 지형이 다양한 높이에 배치되므로,
플레이어는 "어느 높이에 다리를 놓아야 건널 수 있는가"를 판단해야 한다.

## 2. 악기 역할 시스템

### 2-1. 설계 철학

기존에는 21개 악기가 "다리 형태 + 소리"만 달랐다. 이제 각 악기에 고유한 **구조적 역할**을 부여해서, 어떤 악기를 어디에 배치하느냐가 전략이 되도록 한다.

악기를 세 가지 카테고리로 나눈다.

| 카테고리 | 역할 | 아이콘 색 |
|---------|------|----------|
| 🟦 건설형 | 플레이어가 걸어가는 발판 | 파란 계열 |
| 🟫 지지형 | 발판은 아니지만 구조를 강화 | 갈색 계열 |
| 🟨 특수형 | 독특한 물리/환경 효과 | 노란 계열 |

### 2-2. 전체 역할 표

| # | 악기 | 카테고리 | 역할 이름 | 효과 |
|---|------|---------|----------|------|
| 1 | Piano | 🟦 건설 | 기본 발판 | 표준 직선 다리. 특수 효과 없음. 가장 안정적 |
| 2 | Guitar | 🟦 건설 | 아치 다리 | 곡선형. 양 끝이 아래로 휘어 넓은 간격을 커버 |
| 3 | **Drum** | 🟫 지지 | **기둥 (Pillar)** | 수직 기둥을 세움. 밟을 수 없지만, 위에 놓인 다리가 무너지지 않음 (FallingObstacle 내성) |
| 4 | Flute | 🟨 특수 | **바람막이** | 반경 3칸 이내의 WindZone 힘을 70% 감소 |
| 5 | Violin | 🟦 건설 | 탄성 다리 | 곡선형 + 약간의 바운스 (낙하 충격 흡수, 착지 시 위로 살짝 튕김) |
| 6 | **Bass** | 🟫 지지 | **토대 (Foundation)** | 넓고 두꺼운 블록. 밟을 수 있고, 인접한 다리 2개의 흔들림을 제거 (FallingObstacle 위에 놓으면 무너지지 않게 고정) |
| 7 | Xylophone | 🟦 건설 | 스코어 다리 | 지그재그형. 이 위를 걸으면 효율 점수 +5 보너스 |
| 8 | Bell | 🟨 특수 | **신호탄** | 반경 4칸의 아이템(InstrumentPickup)을 자석처럼 끌어당김 |
| 9 | **Trumpet** | 🟨 특수 | **도약대** | 밟으면 위로 크게 튕김 (force=18). 높은 곳에 도달할 때 필수 |
| 10 | Saxophone | 🟦 건설 | 활주로 | 곡선형 + 위를 걸으면 이동속도 1.5배 가속 |
| 11 | Harp | 🟨 특수 | **감속 필드** | 반경 3칸의 MovingObstacle 이동속도를 50% 감소 |
| 12 | **Organ** | 🟦 건설 | **대형 플랫폼** | 폭 2.5배의 넓은 발판. 안전지대 역할 |
| 13 | Synth | 🟨 특수 | **방향 점프대** | 밟으면 45도 대각선 방향으로 발사 (방향은 배치 시 선택) |
| 14 | Marimba | 🟦 건설 | 연결 다리 | 지그재그형. 인접한 BridgePiece와 자동으로 연결선이 생김 (간격을 채움) |
| 15 | **Clarinet** | 🟨 특수 | **레이저 차단막** | 이 다리를 통과하는 레이저 빔을 차단함 |
| 16 | Harmonica | 🟨 특수 | **중력 완충** | 반경 3칸에서 플레이어 낙하속도를 60% 감소 (안전망 역할) |
| 17 | Banjo | 🟦 건설 | 줄 다리 | 곡선형 + 위를 걸으면 좌우로 흔들림 (밧줄다리 느낌). 낙하 위험 있지만 폭이 넓음 |
| 18 | Cello | 🟫 지지 | **공명 (Resonance)** | 주변 반경 3칸의 모든 다리 콜라이더 크기를 20% 확장 (밟기 쉬워짐) |
| 19 | **Tuba** | 🟫 지지 | **벽 (Wall)** | 수직 벽을 세움. 플레이어는 벽타기 가능. MovingObstacle을 막아줌 |
| 20 | Accordion | 🟦 건설 | 확장 발판 | 배치 후 2초에 걸쳐 폭이 점점 넓어짐 (1x → 2x) |
| 21 | Kalimba | 🟨 특수 | **수리** | 인접 다리의 내구도 회복. FallingObstacle 위 다리의 낙하 타이머를 리셋 |

### 2-3. 카테고리별 전략적 의미

**🟦 건설형** — 플레이어가 밟고 지나가는 발판. 이걸 안 놓으면 건널 수 없다.
점수를 높이려면 최소한의 건설형만 사용해야 한다.

**🟫 지지형** — 발판을 보강하거나 구조적 안정성을 높인다.
Drum 기둥 위에 Piano를 놓으면 FallingObstacle 영역에서도 무너지지 않는다.
Bass 토대 옆에 놓인 다리는 흔들림이 없다.
점수에 포함되지만, "구조적으로 필수"인 상황이 있어서 전략적 판단이 필요하다.

**🟨 특수형** — 환경을 변화시키거나 플레이어에게 특수 능력을 준다.
Flute는 바람 구간에서, Clarinet은 레이저 구간에서, Trumpet은 높은 곳에서 각각 필수적이다.
"이 스테이지에서 어떤 특수형이 필요한가"를 파악하는 것이 공략의 핵심.

### 2-4. 시너지 예시

```
Stage 8 "Gravity Shift" 공략 예시:

  GravityFlip 영역         높은 플랫폼
      ┌───────┐              ┌──┐
      │ ↑↓↑↓  │              │  │
──────┘       └──────────────┘  └──── (Goal)

전략:
- GravityFlip 영역 앞에 Harmonica(중력 완충) 배치 → 반전 시 낙하속도 감소
- 높은 플랫폼까지는 Trumpet(도약대)로 점프
- 플랫폼 위에 Organ(대형 발판)으로 안전하게 착지
```

```
Stage 10 "Laser Symphony" 공략 예시:

  레이저①   레이저②   레이저③
    ║         ║         ║
────╨─────────╨─────────╨──── (Goal)

전략:
- 각 레이저 앞에 Clarinet(차단막) 배치 → 레이저 무력화
- 차단막 사이에 Piano(기본 발판) 최소한만 배치
- 효율적 공략: Clarinet 3개 + Piano 2개 = 5개로 Perfect
```

## 3. 일시정지 메뉴

### 3-1. ESC 키 동작

Build Phase / Play Phase 어디서든 ESC를 누르면 게임이 일시정지되고 메뉴가 표시된다.

```
┌──────────────────────────┐
│                          │
│     ⏸ 일시정지            │
│                          │
│     [ 계속하기 ]          │
│     [ 빌드 재시작 ]       │  ← BridgeBuilder.ClearAll() + BuildPhase 재시작
│     [ 스테이지 선택 ]     │  ← (미래 확장용)
│     [ 설정 ]             │  ← 볼륨 슬라이더
│     [ 메인 메뉴 ]         │
│                          │
└──────────────────────────┘
```

### 3-2. 구현 포인트

- `Time.timeScale = 0` + `Time.unscaledDeltaTime`으로 UI 애니메이션
- 일시정지 중에도 BGM은 계속 (다만 볼륨 30%로 감소)
- ESC 다시 누르면 해제
- Play Phase에서 "빌드 재시작"은 확인 팝업 표시 ("다리가 모두 초기화됩니다. 계속하시겠습니까?")

### 3-3. R키 빠른 재시작

Play Phase에서 R을 누르면 확인 팝업 없이 바로 빌드 페이즈 재시작.
(반복 시도 시 빠른 루프를 위해)

## 5. 높이 가이드 시각 연출

### 5-1. 높이 선택 시 화면 표시

```
현재 높이: 6 (y=1.0)

         ────────────────── y=3.0 (키 0)
         ────────────────── y=2.5 (키 9)
         ────────────────── y=2.0 (키 8)
         ────────────────── y=1.5 (키 7)
  ▶▶▶▶  ══════════════════ y=1.0 (키 6) ◀◀◀◀  ← 선택된 높이 (밝은 색)
         ────────────────── y=0.5 (키 5)
         ────────────────── y=0.0 (키 4)
         ────────────────── y=-0.5 (키 3)
         ────────────────── y=-1.0 (키 2)
         ────────────────── y=-1.5 (키 1)
```

- 선택된 높이: 밝은 노란색 실선
- 나머지 높이: 연한 회색 점선 (높이 가이드 OFF면 숨김)
- 판정선과 높이 가이드 교차점에 고스트 다리 미리보기

### 5-2. 고스트 미리보기

판정선의 현재 X 위치 + 선택된 높이 Y 위치에, 현재 선택된 악기의 다리 형태가 반투명(alpha 0.3)으로 실시간 표시된다. 악기를 바꾸면 고스트 형태도 즉시 변한다.

## 7. 개편에 따른 스테이지 재설계 방향

높이 시스템 + 악기 역할이 들어가면, 스테이지 설계 철학이 바뀐다.

### 7-1. 기존 vs 신규

| 기존 | 신규 |
|------|------|
| "다리를 몇 개 쓸 것인가" 만 고민 | "어떤 악기를, 어떤 높이에, 어디에 놓을 것인가" 3차원 고민 |
| 모든 다리가 y=0에 일렬 | 다양한 높이에 다리가 분포 → 계단, 절벽, 터널 구조 가능 |
| 악기 선택이 소리만 바꿈 | 악기 선택이 전략적 결정 (레이저 구간엔 Clarinet 필수) |

### 7-2. 스테이지별 핵심 퍼즐 예시

| Stage | 핵심 퍼즐 | 필수 악기 역할 |
|-------|----------|--------------|
| 1 | 단순 구덩이 건너기 | Piano (높이 4) |
| 3 | 바람 구간 통과 | Flute (바람막이) |
| 4 | 무너지는 발판 위 통과 | Drum (기둥) + Piano (발판) |
| 5 | 가시밭 위 높은 다리 | Piano (높이 7~8) |
| 8 | 중력 반전 + 높은 곳 도달 | Trumpet (도약대) + Harmonica (완충) |
| 10 | 레이저 3개 통과 | Clarinet (차단막) × 3 |
| 12 | 복합: 바람 + 레이저 + 바운서 | Flute + Clarinet + 최소 건설 |
| 15 | 모든 기믹 | 전 악기 활용 |

## 9. 데이터 구조 변경점

### 9-1. InstrumentData 추가 필드

```csharp
[Header("역할")]
public InstrumentRole role;           // 건설 / 지지 / 특수
public InstrumentAbility ability;     // 고유 능력 enum
public float abilityRadius = 3f;      // 능력 적용 반경
public float abilityStrength = 1f;    // 능력 강도

[Header("역할 설명")]
public string roleName;               // "기둥", "바람막이" 등
[TextArea] public string roleDescription;
```

### 9-2. InstrumentRole / InstrumentAbility enum

```csharp
public enum InstrumentRole { Build, Support, Special }

public enum InstrumentAbility
{
    None,           // Piano — 기본
    Pillar,         // Drum — 수직 기둥
```
